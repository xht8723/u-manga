# U-Manga

[English](README.md) | **简体中文**

[下载 Windows x64 版](https://github.com/xht8723/u-manga/releases/latest/download/U-Manga.exe) · [版本发布](https://github.com/xht8723/u-manga/releases)

U-Manga 是一款 Windows 漫画阅读、翻译与编辑应用。导入自己的漫画，选择本地模型或翻译服务，即可在同一个工作区完成原稿阅读、文字识别、翻译、清理和排版。

你可以直接在电脑上使用，也可以开启本地服务器，通过手机或平板浏览器访问书库。存储和处理任务统一由桌面应用负责。

## 功能介绍

### 书库与阅读

- 导入图片文件夹、PNG/JPEG/WebP 图片、CBZ/ZIP 压缩包和 PDF。
- 整理书籍与章节，编辑书籍信息和封面，调整页面顺序，标记章节已读或未读。
- 提供网格、卡片和列表视图，以及搜索、排序和筛选。
- 支持连续滚动与分页阅读、缩略图导航、缩放，以及原图与译图切换。
- 开启**边读边译**，在阅读过程中提交翻译任务。
- 分别自定义日间、夜间主题和阅读外观。阅读滤镜不会改变导出图片。
- 即时切换简体中文或英文界面，也可跟随系统语言。

### 自动与手动翻译

- 使用内置检测模型，在本地识别漫画文字区域。
- 选择**本地 OCR**，先在电脑上识别文字，再将文字发送给所选翻译服务。
- 选择 **Vision**，由兼容图像输入的服务读取检测到的文字裁剪图。
- 支持 Manga OCR 和多语言 PP-OCR 模型包，可使用 CPU 或受支持的 DirectML 加速。
- 按页、章节或整本书翻译。批量翻译可选择**跳过已有译文的页面**或**替换现有成果**。
- 将指定页面排除在批量翻译之外，同时保留这些页面。
- 准备手动翻译页面，由你自行填写译文。
- 可附带前几页已有的原文对话，帮助模型理解省略、指代和歧义。

### 翻译服务与提示词

- 连接本机或其他电脑上的 **Ollama**，使用自行安装的模型。
- 支持 **OpenAI 兼容 Chat Completions**、**OpenAI Responses**、**Anthropic** 和 **Gemini** 服务。
- 支持 **Google Cloud Translation**、**Microsoft Translator**、**DeepL** 和**百度翻译**。
- 可选择结构化回复，或使用**简易翻译模式**：将同一页的文字一起发送，以编号回复；内容较多时自动分批。
- 为不同服务配置文字翻译、简易文字翻译、Vision 和术语检测提示词，并预览示例请求。
- 在模型支持的情况下，控制是否启用思考模式。

可用语言和能力取决于所选 OCR 模型包、模型及服务。Ollama 程序及其模型需单独安装和管理。

### 原文清理与译文排版

- 使用纯色填充，或通过 **Manga LaMa**、**Manga AOT**、**MI-GAN** 在本地修复背景。
- 分别设置 OCR 和清理设备；无法使用加速时会显示 CPU 回退情况。
- 支持横排、竖排、自动字号适配和整块文字居中，竖排各列保持相同的起始高度。
- 使用内置备用字体和系统已安装字体。
- 设置文字颜色，以及描边开关、颜色和粗细。
- 导入已清理的背景、手动确认纯色清理，或保留背景并仅添加译文。

### 区域编辑

- 选择、绘制、移动、缩放或删除文字区域。
- 修改原文和译文，或单独对某个区域重新识别、重新翻译。
- 调整坐标、文字方向、字体、字号、颜色、描边和清理方式。
- 按区域保存或放弃修改，并对支持的草稿操作进行撤销、重做。
- 在当前页面查看处理进度和详情；保存失败时保留草稿。

### 每本书独立的术语表

- 为每本书维护独立术语表，统一角色名、地名和专有名词的译法。
- 搜索、编辑、添加术语，或批量删除所选条目。
- 导入、导出 CSV/TSV 文件，导入时预览内容并选择冲突处理方式。
- 可让 LLM 在翻译过程中自动识别并保存新术语。
- 从书籍操作、编辑器和浏览器界面查看、编辑术语表。

术语表和自动检测均可选用。不同服务的支持范围有所差异；DeepL 使用配置好的托管术语表 ID。

### 后台任务

- 将处理工作加入队列，查看检测、OCR、翻译、术语检测、清理和排版进度。
- 暂停、继续、重试或取消单个任务，也可使用**全部开始 / 全部停止**。
- 同一本书每次处理一个页面操作，不同书籍之间可调整并发数量。
- 利用已保存的检查点和成功结果缓存继续中断的工作。
- 后台处理时仍可阅读和编辑。

### 手机与平板访问

- 在书库中通过**开启服务器**启动内置服务。
- 打开连接地址或扫描二维码，然后输入共享密码登录。
- 浏览书库，阅读原图或译图，提交翻译并管理任务。
- 修改区域文字、删除区域和编辑书籍术语表。
- 使用紧凑的移动端布局，语言、主题和阅读选项保存在当前浏览器中。

使用时需保持 U-Manga 运行，并让电脑保持唤醒。服务通过 HTTP 在可信局域网内使用；外出访问需另行配置私有 VPN。精细的区域几何与排版编辑、模型配置和书库管理仍在桌面端完成。

### 导出与存储

- 将整本书或指定章节导出为 **CBZ**、**PDF** 或 **PNG 图片**。
- 保留原始文件，编辑内容和生成的资源单独存放在书库中。
- 符合条件的文字或排版修改会复用已保存的清理背景，只重新排版。
- 服务凭据保存在操作系统的凭据存储中。

原始文件通过链接使用，请保持其可访问。本地 OCR 和背景清理在电脑上运行；翻译服务会根据所选流程接收需要的文字或图像裁剪内容。

## 开始使用

1. 在 Windows x64 上运行便携版 **U-Manga.exe**。应用需要 Microsoft WebView2。
2. 选择书库位置、界面语言、翻译语言和处理流程。
3. 下载所选的可选 OCR 与清理模型包；需要自动翻译时配置翻译服务。文字区域检测模型已内置。
4. 添加书籍、整理章节，进入阅读器或编辑器。
5. 翻译并检查效果，根据需要修正，再导出成品。

运行发布版无需安装 Python、Node.js 或 CUDA。翻译服务可能需要账户或 API 密钥，并可能按请求收费。服务器功能可选，只会在手动开启后运行。

## 从源码构建

U-Manga 使用 **Tauri 2**、**Rust**、**Svelte 5** 和 **TypeScript**。

在 Windows x64 上安装 Rust MSVC 工具链、Visual Studio C++ 构建工具与 Windows SDK、Node.js、pnpm，以及 Python 3.10 或更新版本，然后在仓库根目录运行：

```powershell
.\scripts\build.ps1
```

如果 Python 不在 PATH 中，可添加 `-PythonExecutable <path-to-python.exe>`。脚本会恢复锁定版本的依赖，执行前端与原生检查，构建并发布 `release/U-Manga.exe`，随后清理可重新生成的构建输出。开发时可用 `-KeepBuildCache` 保留这些文件。

仓库已包含随应用打包的构建资源。使用 `-PrepareAssets` 重新准备这些资源时需要联网和 7-Zip；编译应用不需要下载可选模型包。
